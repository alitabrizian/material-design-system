pb-list is a container of pb-list-items for plain, navigation and action lists: one-, two- or three-line items with optional leading icons or avatars and trailing text.

API reference

pb-list-item inputTypeDescription
title, subtitle, line3stringUp to three lines of text.
iconstringLeading icon name.
avatarstringLeading avatar image URL.
metastringTrailing supporting text.
hrefstringMakes the item a link (and the list a navigation list).
selected, disabledbooleanActivated or disabled state.
(clicked)voidThe item was clicked.
