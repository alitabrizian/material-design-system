Buttons trigger an action or event, such as submitting a form or opening a dialog. pb-button renders a native button, or a link when given an href, in the Material 3 text, elevated, outlined, filled and tonal appearances, plus icon buttons and FABs.

API reference

InputTypeDescription
variant'text' | 'filled' | 'tonal' | 'outlined' | 'elevated' | 'icon' | 'fab' | 'mini-fab' | 'extended-fab'The M3 button type. Defaults to 'text'.
hrefstringRenders a link instead of a button.
iconstringIcon name for the icon, fab and mini-fab variants.
iconStart, iconEndstringIcon name before or after the label.
type'button' | 'submit' | 'reset'The native button type. Defaults to 'button'.
disabledbooleanDisables the button.
disabledInteractivebooleanKeeps a disabled button focusable and hoverable, e.g. for a tooltip explaining why.
showProgressbooleanReplaces the content with a progress spinner.
aria-labelstringAccessible name; required for icon-only buttons.
