pb-select is a form control for selecting a value from a set of options: a trigger inside an M3 form field that opens a listbox panel.

API reference

InputTypeDescription
[(value)]T | nullThe selected option. Also works with ngModel and formControl.
placeholderstringShown while nothing is selected.
hideSingleSelectionIndicatorbooleanHides the check mark on the selected option.
pb-option value, disabledThe option's value and state; its content is the label.
label, supportingText, errorText, appearance, required, disabled, blockShared by every text field.
