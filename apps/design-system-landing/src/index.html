یک زبان طراحی، چهار فریم‌ورک

اپلیکیشن بعدی شما از همین‌جا شروع می‌شود.

کامپوننت‌های Material 3 با توکن‌های مشترک رنگ، تایپوگرافی، سایه و فاصله‌گذاری؛ برای تیم‌هایی که با Angular، Blazor، React یا Svelte کار می‌کنند.

دیزاین‌سیستم خود را بر اساس فریم‌ورک انتخاب کنید

  • Angular کتابخانه‌ی @partobita/design-system-angular روی Angular Material
  • Blazor پکیج NuGet PartoBita.DesignSystem.Blazor برای .NET
  • React همان توکن‌ها و کامپوننت‌ها برای اپلیکیشن‌های React
  • Svelte کامپوننت‌های سبک و سریع با همان زبان طراحی

هرچه برای ساختن بهترین اپلیکیشن لازم دارید

از اپلیکیشن‌های اداری داده‌محور تا داشبوردها، همه‌ی محصولات پرتوبیتا یک ظاهر و یک رفتار دارند.

  • palette

    توکن‌های مشترک

    رنگ، تایپوگرافی، شکل، سایه، حرکت و فاصله‌گذاری از یک منبع واحد می‌آیند و همه‌ی فریم‌ورک‌ها از آن پیروی می‌کنند.

  • contrast

    چهار تم آماده

    Rose & Red، Azure & Blue، Magenta & Violet و Cyan & Orange، با یک ویژگی data-theme عوض می‌شوند.

  • text_fields

    تایپوگرافی فارسی

    مقیاس تایپوگرافی تیم طراحی با فونت یکان‌بخ، از Display تا Caption، با اعداد فارسی.

  • layers

    Material 3

    هر مقدار کامپوننت با توکن‌های Angular Material 22 تطبیق داده شده است.

  • verified

    بدون رنگ هاردکد

    بیلد هر رنگی را که از توکن‌ها نیاید رد می‌کند؛ پس تغییر تم همه‌جا درست کار می‌کند.

  • cloud_off

    بدون وابستگی به CDN

    فونت‌ها و آیکون‌ها داخل پکیج هستند و در شبکه‌ی داخلی سازمان هم بی‌نقص نمایش داده می‌شوند.

اپلیکیشن‌های سازمانی با Angular و Blazor

کامپوننت‌های واکنش‌گرا و پرسرعت برای نرم‌افزارهای داده‌محور، با مستندات زنده و نمونه‌کد برای هر کامپوننت.

  • Data Grid با مرتب‌سازی، فیلتر، گروه‌بندی و ویرایش
  • Datepicker، Timepicker و فرم‌ها با اعتبارسنجی
  • Tree List، Chips و Tag Box برای داده‌های سلسله‌مراتبی
  • Dialog، Snackbar، Menu و Sidenav برای ناوبری

React و Svelte در راه‌اند

  • پکیج @partobita/design-tokens از همین حالا قابل استفاده است
  • همان چهار تم و همان مقیاس تایپوگرافی
