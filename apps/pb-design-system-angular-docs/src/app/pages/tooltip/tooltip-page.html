pbTooltip provides a text label that is displayed when the user hovers over or keyboard-focuses an element.

API reference

InputTypeDescription
pbTooltipstringThe tooltip text.
pbTooltipPosition'below' | 'above' | 'before' | 'after'Where it appears. Defaults to below.
pbTooltipDisabledbooleanTurns it off.
pbTooltipShowDelay, pbTooltipHideDelaynumberDelays in milliseconds.
