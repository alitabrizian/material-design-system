Badges are small status descriptors for UI elements: a small circle with a count or short text pinned to a corner of the element it annotates.
Text with a badge Text with a large badge Text with a dot badge
Toggle badge visibility mail notifications

API reference

InputTypeDescription
pbBadgestring | numberThe badge content. An empty string with pbBadgeSize="small" is a dot.
pbBadgeSize'small' | 'medium' | 'large'Badge size.
pbBadgePosition'above after' | 'above before' | 'below after' | 'below before'Corner the badge is pinned to.
pbBadgeOverlapbooleanOverlaps the host (icons) instead of sitting beside it (text).
pbBadgeHidden, pbBadgeDisabledbooleanHides or dims the badge.
pbBadgeDescriptionstringScreen-reader description of what the badge means.
