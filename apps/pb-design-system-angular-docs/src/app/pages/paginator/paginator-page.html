pb-paginator provides navigation for paged information: a page-size select, a range label and first/previous/next/last buttons.

Page {{ pageIndex() + 1 }}, {{ pageSize() }} per page

API reference

Input / outputTypeDescription
lengthnumberTotal number of items.
[(pageIndex)], [(pageSize)]numberThe current page (zero-based) and page size.
pageSizeOptionsnumber[]Choices in the page-size select.
showFirstLastButtons, hidePageSize, disabledbooleanLayout and state options.
itemsPerPageLabel, firstPageLabel, previousPageLabel, nextPageLabel, lastPageLabelstringLabels, for localization.
(page)PbPageEventThe page or page size changed.
